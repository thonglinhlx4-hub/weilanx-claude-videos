# 金线一笔风（gold-thread）——风格配方卡（设计稿，代码未写）

一句话：纯黑星空底上，一支会发光的金色光笔一笔到底，画出图表、道具、文字，再拖成一条线把观众带进下一场。

## 节奏
- 225.7 秒仅 7 个硬切 / 8 个镜头，平均镜头 28 秒；真正的"切"几乎都由光笔转场完成（一镜到底）。
- 硬切只出现在两类地方：真人插入（菜市场老板）、1~1.5 秒的短闪（54.0、149.6 秒）。
- 内容节拍跟着口播走：一句字幕 ≈ 一个画面变化，约 2.5~3.5 秒一拍。
- 运动强度：开头 0~4 秒最高（钩子），之后多为低运动 + 周期性尖峰（每场光笔转场）。

## 版式
- 16:9，主体居中偏上，字幕固定底部居中一行。
- 图表：深蓝细网格坐标系占画面中部 60%，右上角红色数码管读数框（标签 + LED 数字）。
- 叙事板：圆角金色发光框（黑板 / 路牌 / 泥板），框内左对齐公式或表格。
- 大标题极少，偶尔左上灰白粗黑体（"学函数到"）。

## 配色
- 底：近黑 #0a090d / #040509（76% 画面亮度 < 0.12），星点 + 远处暖色散景。
- 主色：金色光线，强调色梯度 #61442d → #9a7a58 → #debc92，核心近白，外层琥珀光晕。
- 点缀：数码管红 #ff3b2f 系（数字、警示）、蔬菜绿描边、冷蓝紫白（情绪曲线 / 网格），橙红（负面趋势线）。
- 规则：同屏只一条主金线，其他颜色只在"分类对比"时出现。

## 字体层级
1. 字幕：细宋体 / 明体白字，约 2.2% 画高，无描边，轻阴影。
2. 图中标注：小号宋体灰白；坐标刻度更小、更暗。
3. 数字：红色七段数码管（LED 发光，带虚影）。
4. 公式：衬线斜体（LaTeX 风），金或白。
5. 强调大字：发光描边大数字（如"70"）、粗黑体灰白短语。

## 入场 / 转场
- 入场：光笔笔头（亮白点 + 十字星芒）沿路径描出轮廓，0.3~0.6 秒画完一个图形，ease-out；描完后外发光保留。
- 文字：跟在笔头后淡入，或逐字发光。
- 转场（招牌）：上一场元素被一条金线"收走"——画面往一侧推 + 运动模糊，线变成宽丝带甩出画面（约 10~15 帧），再在黑场中继续游走、转折，落笔画出下一场第一个元素。整段 1~1.5 秒。
- 图表数据：曲线由笔头从左往右画出，同时数码管读数滚动。
- 情绪爆点：一点炸开成上百条细光丝（"趋势 = ?"）。

## 配乐卡点
- BGM ≈ 129~131 BPM，一小节约 1.84 秒，整片 -12 LUFS，口播在上。
- 0~3.7 秒铺垫，3.71 秒第一个重拍 = 钩子落点（f(x) 白菜 ? 画完）。
- 重拍候选 28.6 / 31.7 / 33.5 / 49.1 秒，对应泥板数表逐行亮起等节点。
- 转场笔线的"甩出"落在小节线上；重拍前约 0.7 秒画面先收暗。

## 招牌画面
- 光笔写 f(x) + 物件 + 问号的开场
- 网格坐标 + 红色数码管读数
- 发光圆角框里的公式 / 表格
- 一点爆成万千光丝
- 线条甩成丝带的转场
